# 案件カード：担当者割当と対応日

カード右上の「未割当／ここから割り当て」（割当済みは担当者名）を社員以上が押すと、案件エリアを扱える社内担当者だけを選択できます。担当者の変更・解除も同じ場所で行います。協力業者と顧客には選択UIを出しません。社外操作はサーバーでも拒否します。

その下の日付は、**緊急度Sまたは依頼内容・工事分類に「漏電」がある案件なら「初回対応日（実績）」**、その他なら**「対応予定日」**です。スクリーンショットの案件300880-1は緊急度A・漏電記載なしのため「対応予定日」となります。

- 初回対応日は、最初の連絡・手配など実際の初動があった日を入力します。未来日は不可、確認根拠・訂正／解除理由を5文字以上入力します。**現調実施日とは別**です。現地に行った日だけを示したい場合は案件詳細の「現地対応日（現調実施日）」を使用します。
- 通常案件の対応予定日は将来・過去の日を入力できます。過去の予定は過去のまま表示し、実績に自動変換しません。補足は任意です。
- いずれもJST暦日で入力し、日付の訂正・解除と記録者・記録時刻・前後値を監査履歴に残します。社内担当者とエリア権限が必要で、協力業者・顧客には日付列と履歴を返しません。
- 列は `cases.first_response_date` と `cases.response_planned_date` です。既存 `surveyDate`・`constructionDate`・`completedAt`・進捗・ステータスは変更しません。区分変更時にも反対側の日付を勝手に消さず履歴を維持します。
- 0050マイグレーションは2列と専用監査テーブルの追加のみで、既存DBへ**一度だけ適用済み**です。手動適用済みの旧SQLを一括再実行しないでください。
