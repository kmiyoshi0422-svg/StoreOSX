# Store OSX 見積支援 — 利用ガイド

## 開き方

既存Store OSXの左メニュー「見積支援・依頼PDF」、または案件詳細の「見積書」タブにある「見積支援で案を作る」から開きます。案件詳細から開くと保存先の案件があらかじめ選択されます。

この画面は**見積案の作業スペース**です。作成した案は案件に下書きとして保存されますが、既存の提出用見積書・案件の見積金額・利益・発注データは変更しません。提出前に人が工事範囲・数量・条件・税区分・単価を確認してください。

## 三つの入力方法

| 方法 | 使い方 | 特に確認すること |
| --- | --- | --- |
| 寸法別商品単価 | 「寸法別商品単価」でフォレティア50の幅・高さをmmまたはcmで入力し、台数を指定して「見積案に追加」。参考ページと同じ寸法帯へ切り上げます。 | 対象はネイチャー／ラダーコード、ループ／チェーン仕様の**本体参考価格**のみ。取付費・送料・オプション・色・在庫・最新の価格を確認。 |
| 標準施工単価 | 「標準施工単価」で工事項目を検索し、下限・標準・上限から明細に追加。数量・単価はあとから修正できます。 | プロジェクト共有の`標準施工単価表_2026_06_v2.xlsx`から117件を収録。原本は税区分を明記していないため画面では税抜試算と仮置き。提出前に確認。 |
| 依頼PDF | 「依頼PDF → 見積案」に12MB以内のPDFを選択。AIが依頼番号・店舗・作業・数量・寸法を抽出し、**項目名・規格・単位が厳密一致**するものだけ候補単価を入力します。 | AI抽出は誤認識することがあります。不明な仕様や品番は金額を推測せず空欄にします。元PDFと照合して修正してください。 |

右の「試算サマリー」は税抜小計・概算税額・税込試算額を表示します。未設定の価格や数量がある場合は、表示額は**総見積額ではありません**。価格の根拠は明細ごとに残ります。

保存するには案件を選んで件名・明細を確認し、「案件の見積案として保存」を押します。右側の「この案件の保存済み見積案」から再表示・編集できます。他画面で更新された後の古い内容は競合として拒否します。依頼PDFの番号が選択案件と違う場合は保存前に確認ダイアログを出します。

## 権限と価格の扱い

最高管理者・管理者は価格参照、PDF解析、明細編集、下書き保存ができます。役員は価格と既存の見積案の閲覧のみ。社員・協力業者・顧客にはページ・単価API・見積案APIを公開しません。役員で閲覧エリアが限定されている場合はエリア外案件の案も閲覧できません。

フォレティア価格は[参考ページ](https://foretia-price-kei.maverick-4654.chatgpt.site/)の**2026-09-21スナップショット**で自動更新されません。[販売店の商品情報](https://www.bicklycurtain.com/c/blind/1001631)で発注時の製作制限、価格、送料を必ず再確認してください。幅280–2400mm・高さ250–2800mm・1cm刻み、幅580mm未満は高さ2500mm以下、最大9㎡だけをこの画面で算定します。高さ2800mm超の特注は自動見積しません。

## 現時点の自動化の境界

**依頼PDFから作業と候補単価を抽出するところまで**を実装しました。完成した見積案から正式な提出用見積書PDFへの変換・承認・自動提出、既存の見積金額への反映はまだ実装していません。したがって、PDFの内容を読み込んだだけで対外提出されることはありません。
