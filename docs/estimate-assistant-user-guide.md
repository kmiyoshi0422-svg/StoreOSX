# Store OSX 見積支援 — 利用ガイド

## 開き方と利用権限

案件詳細の右上「**この案件から見積案を作る**」を押すと、その案件を選択した見積支援画面へ進みます（社員にも表示）。従来の見積書タブや左メニュー「見積支援・依頼PDF」からも開けます。「標準施工単価マスタ」は左メニュー、または見積支援画面上部から開けます。

**最高管理者・管理者・役員・社員**は、見積支援・単価マスタの閲覧、見積案の作成／編集／承認、正式見積書PDFのダウンロードを利用できます。案件のエリア制限は引き続き適用されます。**協力業者・顧客には画面もAPIも公開しません。**社員への今回の金額開示はこの見積支援機能に限ったもので、ほかの金額画面の権限は変更していません。

## 見積案を作る

| 入力方法 | 操作 | 確認事項 |
| --- | --- | --- |
| **定型メニュー（初期表示）** | ブラインド／GT蓋・GT内かご／捕虫器取付／はいはい店番取付から項目を選択 | 数量は必ず空欄で追加。定型メニュー自身に税抜単価が登録されている場合だけその設定単価を表示。分類・項目・単位・任意単価は社員以上が画面上で追加・編集・非表示化可能 |
| 自由見積 | 「自由見積」から空欄の明細を追加し、項目名・数量・単位・税抜単価・備考を編集 | 標準単価に連動せず、数量・単価は入力するまで未確定。0円単価は有効 |
| **登録済み案件情報** | 案件詳細から開き「案件情報から見積案を生成」を押す | PDF再アップロード不要。元PDFがあれば登録情報と照合。作業名・明記された数量・根拠だけを抽出し、数量不明は空欄。単価は常に自由入力 |
| ブラインド参考価格 | ブラインド分類の「フォレティア50の寸法別参考価格を計算」または専用タブを使う | 入力寸法に基づく参考本体価格を**明示操作した場合だけ**明細へ追加。取付費・送料・条件は別途確認。価格は2026-09-21の固定スナップショット |
| 標準施工単価（手動参照） | 参考価格タブで工事項目を検索し、下限・標準・上限から手動で選ぶ | 2026年6月版の117件。**AI抽出には自動適用しない**。Excel原本に税区分明記なしのため税抜試算として提示 |
| 依頼PDF | 12MB以内のPDFをアップロードして作業・数量・寸法・原文根拠・ページ番号を抽出 | 左の原本と右の見積明細を照合。数量不明は空欄。標準単価・フォレティア価格を自動代入しない |

**PDFから案件登録した案件は元PDFの参照を保存します。**登録済みPDFがある案件は、サーバーがアクセス可能な案件の原本を取得してAIに渡し、登録済みテキストとの相違を表示します。PDF側の依頼番号が登録案件と異なる場合は生成を停止します。番号をPDFから読めない場合は未確認と表示します。明細の根拠はPDF引用か案件テキスト引用かを区別します。**過去の案件で元PDFが保存されていない場合は復元・表示できず、登録済みテキストのみで候補を作成します。**ページ番号と引用もAI推定なので必ず原本を確認してください。

AI抽出結果はまず「**AI見積候補の確認**」に未採用の状態で表示されます。個別チェックまたは「すべて選択」で選択し、「選択した件数を一括採用」または確認付きの「一括除外」を行ってください。未選択の候補は残り、既存の手入力明細は変わりません。候補が残っている間は下書き保存・承認を止めます。採用した明細の数量・単位・単価が空欄または不正値なら、該当の行と入力欄が赤くなり、試算総額から除外されます。**未入力がゼロになり、再保存するまでは承認できません。**

**AI見積候補には、項目名が標準単価マスタと一致しても単価を自動設定しません。**品番・数量・施工条件を推測せず、PDFと案件情報に書かれた事実だけを転記します。数量は不明なときだけ空欄にし、既知の数量は保持します。単価は人が設定するまで空欄です。単位の記載がないときは仮の「式」を入力して修正可能にします。価格は定型メニューの明示選択（その項目に価格が登録されている場合）、参考価格の明示選択、または自由入力で確定してください。原本の依頼番号が案件番号と異なる場合は候補生成を停止します。

### AI見積候補の判定・修正履歴

左メニュー「**AI見積精度モニタリング**」では7／30／90／365日の生成分を、社員以上かつ許可されたエリア内に限って閲覧できます。候補の**採用・除外操作**は確定時に実行者・日時を保存し、採用明細の**保存済み変更**は項目名・規格・数量・単位・単価・引用・ページ・補足の前後差分を記録します。読み込んだだけの候補と未保存の編集は修正履歴に計上しません。以前の見積は記録開始前のため集計できません。

**採用率＝採用件数÷判定済み件数、除外率＝除外件数÷判定済み件数、採用後修正率＝保存時に1回以上修正された採用候補数÷採用件数。** 未判定候補を分母に入れません。これらは担当者の操作率であり、AIの真の正答率ではありません。見逃された工事・誤った採用は計測できず、精度を断定するには原本と専門家の正解ラベル付き検証セットが必要です。次の改善は表記ゆれ辞書と施工条件・型番の一致根拠を整備し、誤自動単価が増えない範囲で候補率を上げることです。

## 標準施工単価マスタ

画面の「単価を追加」で大分類、分類、工事項目、規格、単位、下限／標準／上限、価格根拠と備考を登録します。既存行は「編集」で改定、「削除」で今後の検索・自動提案から**非表示化**します。削除済み表示と変更履歴から操作種別、前後の価格、操作者IDと時刻を確認できます。元Excelの117件はそのままDBへシード済みで、画面からの変更は元ファイルやすでに承認した見積書を書き換えません。過去の未承認案も自動上書きしません。

## 承認から正式見積書PDFまで

1. 保存先の案件、件名、全明細の**数量・単位・単価**を確認して「案件の見積案として保存」。未入力項目があれば右側の金額は総額ではありません。
2. PDFと明細を照合し、税区分、工事範囲、必要な諸経費、地域差、販売店価格を確認します。変更した場合はもう一度保存してください。
3. 未価格・未数量がなく、最新状態を保存した場合のみ「内容を承認して正式見積書PDFを出力」が有効です。確認ダイアログで確定すると、案件番号・店舗・宛先・発行元・明細・税額・承認者／日時を**承認時点で固定**し、A4 PDFを自動ダウンロードします。
4. 承認後はその案を変更できません。保存済み案で「承認済み」を選ぶと、同じ固定データから「正式見積書PDFを再ダウンロード」できます。再ダウンロード時の案件や単価マスタの更新は、既存の承認PDFに反映されません。修正するには「新しい見積案を作成」で別案を作ってください。

正式見積書の発行元は既存の報告書と同じ**株式会社小林工房／三好 慶**、宛先は**株式会社プレナス 御中**です。A4の複数ページに改ページし、合計と発行者を最終ページに表示します。このPDFはブラウザで都度生成します（サーバーにPDFバイナリは保管せず、承認時の固定データを保管）。メール送信・外部提出・既存見積への転記・案件金額変更は**実行しません**。見積有効期限・支払条件・税区分の原本条件を確かめた上で対外利用してください。
