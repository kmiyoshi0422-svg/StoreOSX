# 報告書の写真組み合わせ・先方署名・A4プレビュー操作ガイド

## Before／After写真の組み合わせ変更

工事完了報告書を開き、**「Before／After写真の組み合わせ」**で施工前写真ごとの施工後写真を選択します。初期状態は工事項目を優先した自動組み合わせです。異なる施工後写真を選ぶと即時保存され、すでに別の施工前写真で使われていた写真は元の組み合わせから外れます。

施工後写真がない箇所は**「施工後なし・単独表示」**を選びます。自動判定へ戻す場合は**「自動に戻す」**を押します。削除済み写真や異なる区分の写真IDは保存時に除外され、存在しない写真を報告書へ補完しません。

## 担当者・先方の電子サイン

現地調査報告書と工事完了報告書の**「確認サイン」**には、担当者用と先方確認者用の2枠があります。先方サインは署名者名を入力し、署名欄へ直接描画して保存します。保存後は署名画像、氏名、署名日時がPDF最終ページの先方確認欄へ表示されます。

保存済みサインは**「サインし直す」**または**「削除」**で変更できます。担当者サインと先方サインは独立して保存されるため、片方の更新で他方は消えません。

## 印刷・PDF前の確認

上部の**「A4レイアウトを確認」**を開くと、実際にPDFへ出力されるA4全ページを確認できます。写真の向き、Before／After、改ページ、所感、担当者サイン、先方サインを確認してください。

全ページのプレビュー生成が完了すると、上部の**「PDFダウンロード」**が有効になります。本文、写真、署名が変更された場合は確認済み状態が解除されるため、再度プレビューしてから出力します。プレビューモーダル内から直接PDFを保存することもできます。
