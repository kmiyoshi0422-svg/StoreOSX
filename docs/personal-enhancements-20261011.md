# 個人担当グラフ・責任者一括割当（2026-10-11）

## 個人担当グラフ

「自分の担当案件」にステータス別と進捗別のドーナツグラフを追加。現在の検索後の担当案件を集計し、件数と割合を凡例・ツールチップに表示します。凡例またはグラフ区分を押してその状態・進捗に絞り込めます。「条件をクリア」で戻せます。0件時は円を描かず、該当案件なしと表示します。進捗未入力は既存集計と同じく未対応へ含めます。担当外案件・金額列は取得しません。検索・グラフは状態を更新しません。

## 未決定案件の責任者一括割当

ダッシュボードの本人限定未決定アラートで案件チェックボックスを選択します。「このページを選択」は表示中10件だけを追加選択。ページをまたいで最大100件選択できます。選択解除も可能。5名から責任者を選び「選択案件の責任者を一括割当」を押すと、対象案件名・依頼番号・責任者・件数を確認する画面が開きます。キャンセル時は変更なし。確認した案件IDを固定して実行します。処理中はボタンを無効化し「割当中…」を表示します。

APIは指定5名の確認済み本人だけに許可。社員・一般admin・外部へ広げません。既存の個別責任者選択権限は変更しません。選択案件をID順にロックし、すべてが許可エリア・依頼日2026年10月1日以降・登録120時間以上・責任者未決定の進行案件であることを再検証します。決定済み、削除、完了、失注、エリア外が1件でも混ざれば全件停止。責任者変更と全案件分の監査を同一トランザクションで保存し、作業担当者・業者・進捗・日付・金額は変更しません。結果後に一覧、詳細、本人集計、監査とアラートを更新します。
