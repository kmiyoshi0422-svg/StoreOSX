# 案件全体の現場メモ 検証記録

## 実装範囲

- 案2として、案件詳細の写真アップロード欄直下へ案件全体の「現場メモ」を配置した。
- メモは種別、本文、記入者、記入者権限、作成日時、更新日時を保持する。
- 写真ごとの既存メモ、案件備考、正式所感とは分離した。
- 最高管理者・管理者・社員・許可案件の協力業者は追加可能、役員は閲覧のみ、顧客は非表示とした。
- 編集・削除は記入者本人だけに限定した。
