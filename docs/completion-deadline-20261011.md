# 専用完了期限と協力業者ハイライト（2026-10-11）

## 専用完了期限

ユーザーが選択した②を採用。案件に `completion_deadline` という日本時間の暦日（YYYY-MM-DD）を追加しました。期限は時間ではなく一日単位の約束日であり、対応予定日・施工予定日・現調日・実際の完了日とは独立です。既存案件は全件未設定から始め、過去の予定・実績・工程日から自動補完しません。

管理者・社員・役員・最高管理者が案件詳細「基本情報」の「完了期限」欄で入力できます。設定・変更・解除の理由は3文字以上必須。変更前後、操作者ID・名前、日時、理由を `case_deadline_logs` に記録します。解除は確認画面付きで、キャンセル時は変更なし。エリア権限をサーバーで再確認し、古い期限を見た画面からの上書きは競合エラーで停止。一般案件更新APIからの直接変更は拒否し、期限更新と監査保存は同一トランザクションで行います。期限変更だけで進捗・作業担当・業者・日付・金額を変更しません。

## 協力業者画面

協力業者は、ログインユーザーに紐づく協力会社へ割当済みの自社担当案件だけの期限を読めます。担当エリアにあるだけの他社案件は期限参照できません。全案件閲覧APIでは期限はnullにマスクし、本人担当API・専用期限参照APIのみ公開します。変更理由・履歴は社内限定。顧客は期限APIを利用できません。金額・社内自由記述の保護は既存仕様を維持します。

「自分の担当案件」では期限サマリー（超過／本日／3日以内／未設定）とカード強調、期限対象のみ表示の切替を追加しました。ダッシュボードには期限の早い順に最大5件を表示し、残りは担当タブへ案内します。担当データは1分ごとに再取得します。

| 期限の条件（JST暦日） | 表示 |
|---|---|
| 期限の3日前～前日 | 黄色、残り日数 |
| 期限当日 | オレンジで強調、本日が期限 |
| 期限翌日以降 | 赤、超過日数 |
| 完了・クローズ・失注 | ハイライト／警告対象外 |
| 未設定・不正日付 | 期限を推測せず対象外 |

期限を過ぎても案件を自動完了させたり、ステータスを戻したりしません。メール・LINE・Resend通知は今回の範囲に含めず、既存の保留を維持します。期限設定後の判定は画面内表示です。
