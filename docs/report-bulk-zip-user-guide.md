# 現調・完了報告書の一括ZIPダウンロード

## 案件から新しく生成する場合

1. 社員以上の権限でStoreOSXにログインし、サイドバーの **報告書一括ZIP** を開きます。管理者は **完了報告書一覧** からも移動できます。
2. 依頼番号・店舗名で検索し、案件ごとに **現場調査報告書** または **施工完了報告書** をチェックします。同一案件の両方を選択することもできます。1回につき2〜8件です。
3. **A4 PDFを生成して確認** を押すと、既存の報告書レイアウトを使い、1件ずつ写真・本文・署名を含むPDFを作ります。生成中は件数と案件番号を表示します。
4. モーダル内で各PDFを切り替え、全ページと写真・署名を確認します。必要に応じて **別タブで全ページを見る** を押してください。各PDFの **この報告書を確認しました** を押すと、そのPDFが確認済みになります。
5. 全件を確認すると **確認した報告書をZIPでダウンロード** が有効になります。先に個別PDFが案件・報告書種別・作成者・ページ数とともに **PDF生成履歴** へ自動保存され、全件の保存完了後にZIPをダウンロードします。ZIPには案件番号・店舗名・種別・案件IDを含む別名のPDFが入ります。
6. 後から確認する際は **PDF生成履歴を確認** を開き、案件・店舗名・日付で検索して各PDFの **再ダウンロード** を押します。個別PDFの保存に失敗した場合はZIPを出さず、既に保存できた件数を表示します。同じ画面のダウンロードボタンから再試行しても同じPDFは重複登録しません。

## 保存済みPDF履歴からまとめる場合

**PDF生成履歴** に表示される、案件に紐づいた現場調査報告書・施工完了報告書だけを2〜8件チェックし、**選択した報告書をZIPで保存** を押します。報告書履歴にまだPDFがない場合は **履歴にない案件から報告書を作る** から上記の生成フローを利用してください。

どちらの経路でもZIP名は日本時間のダウンロード日時入りです。1案件の現調・完了をまとめる場合は `店舗名_依頼番号_現調・完了報告書_YYYYMMDD_HHmm.zip`、複数案件では `最初の店舗名_ほかN案件_現調・完了報告書_YYYYMMDD_HHmm.zip` になります。ZIP内の各PDFには報告書種別と案件IDが付き、同じ店舗名でも区別できます。

## 安全と制限

- 最高管理者・管理者・役員・社員が利用でき、案件・エリアの閲覧権限をAPIで再検証します。協力業者・顧客は一括ZIPを利用できません。
- 案件の一括生成では、**現調の記録や完了状態がない報告書は選択できません**。下書きを完了済みの正式報告書として扱いません。
- 写真が欠損している場合や、1件でもデータ取得・PDF生成が失敗した場合、ZIPは出力しません。写真の代用品を作らず、案件を確認してからやり直してください。
- PDFの合計は80MBまでです。1件ごとの生成には時間がかかるため、時間切れの場合は選択件数を減らしてやり直してください。
- 案件側の生成はブラウザ内でPDFとZIPを組み立て、全件を確認してZIPダウンロードを押した時点で個別PDFを履歴へ保存します。**生成ボタンのみ、またはプレビューを閉じただけでは履歴へ保存されません**。1件30MB以内のPDFだけが履歴に保存でき、全体で80MB以内・2〜8件という上限は維持されます。
- 保存済み履歴の一括ZIPでは既存のPDFファイルそのものを使用します。ZIPに含まれるPDFも案件金額や元の報告書データを書き換えません。

## 検証と既知の範囲

- 合成写真入りA4・3ページのPDFを実ブラウザで生成して2件のZIPに入れ、解凍したPDFがA4・3ページであることを確認しています。
- 実案件を用いたデスクトップ／スマートフォン幅の選択画面を確認しています。既存の履歴には保存済みPDFがないため、本番履歴からの実ファイルZIPは実施せず、権限・ZIP内容・破損時停止をモックファイルで回帰テストしています。
