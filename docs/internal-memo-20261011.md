# 案件詳細の社内メモタブ（2026-10-11）

## 操作

案件詳細の「基本情報」のすぐ右に「メモ」タブを配置。連絡・確認・引き継ぎ事項を改行付きで自由入力し「メモを保存」で確定します。最大10,000文字で、保存中・未保存状態・最終記入者・日本時間の更新日時を表示します。空欄を保存すれば本文を消去できます。

メモは既存備考、正式所感、短文所感、写真メモ、写真タブの現場メモとは独立しています。報告書・見積書へ自動出力しません。既存案件の状態・予定日・担当者はメモ保存で変わりません。

## 権限と保存

最高管理者・管理者・役員・社員が許可エリアの案件で利用できます。協力業者・顧客・未認証利用者は、タブも専用APIも利用できません。金額非閲覧社員へ円・万円等の明示的な金額表記がある本文は全文非表示とし、上書きや金額入り本文の保存を拒否します。単位のない数字や記述の意味までは自動判定できないため、既存の金額権限運用が必要です。

0053の独立テーブル `case_internal_memos` に本文・版番号・更新者・更新日時を保存。一般案件DTOや公開tokenレスポンスへ列を追加せず、案件削除時だけ対応メモを清掃します。親案件ロックと版番号比較で初回保存も同時編集も保護します。

## 入力保護

タブを切り替えても同一案件画面内では入力を保持。ブラウザを閉じる／ページを再読み込みする場合は未保存確認を出します。未保存内容はサーバー自動保存していません。別案件へのSPA遷移は保存を済ませてから行ってください。

他の利用者と競合した場合は上書き停止・入力保持・最新の保存内容を比較表示。「最新の保存内容に戻す」は未保存破棄の確認付き。保存失敗時も本文を消しません。
