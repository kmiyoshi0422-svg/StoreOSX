# 協力業者の全案件閲覧と金額非表示（2026-10-08）

## 権限の範囲

- **協力業者**：案件一覧の全案件を検索し、各案件の概要・現場写真・チェックリストを閲覧できます。管理者が設定した許可エリア、またはエリア未設定時に本人へ割り当てられた案件だけは、これまでの編集範囲を維持します。担当外・エリア外の案件詳細は閲覧専用の専用画面となります。
- **顧客**：従来の閲覧範囲から拡張しません。
- **社内ユーザー**：既存のエリア・ロール・財務閲覧権限を維持します。

## 外部へ見せない情報

協力業者と顧客への案件APIでは見積提出額、原価、実費、予算、請求関連の数値列をサーバー側で伏せます。社内の見積、経費、資料DB、店舗別金額集計、PDF履歴などのAPIは外部ロールから拒否します。担当外案件の電話番号・社内所感・内部メモ・詳細工程／ステータス履歴も表示しません。依頼内容・写真メモ・チェックリスト等のテキストに **円／￥の明示的な金額表現** がある場合は、その自由記述全体を非表示にします（部分伏せ字からの推測を防ぐため）。

担当者名の表示に使う社外向けユーザー一覧はID・氏名・ロール・空のメール欄だけを返し、実メールアドレス、認証ID、ログイン履歴およびエリア設定は返しません。店舗マスタ・設備台帳・アプリ設定の直接APIも社内専用です。

**注意**：写真画像そのものや円／￥を使わない自由表現（例：数字だけ、手書き文字）まで自動的に判別・マスクするものではありません。公開前の現場写真や自由記述に社内の見積・経費情報を混ぜない運用が必要です。新規で全案件を見られるのは協力業者アカウントであり、顧客・未認証ユーザーではありません。

## 漏電の当日対応実績

別件の「今まで全て当日に対応できている」という申告について、現調日／完了日の記録がない案件を架空の日付や完了状態に変えていません。**当日初動**と**当日現調・施工**のどちらを記録するか確定後、確認者・確認日・証拠の有無を残す方針です。
